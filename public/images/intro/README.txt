인트로 컷 이미지 폴더

- intro-01.jpg ~ intro-06.jpg 이름으로 사진을 넣으면 인트로 가운데 이미지가 자동으로 바뀝니다.
- 정사각형(1:1) 사진이 가장 잘 맞습니다. (다른 비율은 가운데 기준으로 잘림)
- 용량은 장당 200KB 이하를 권장합니다. (인트로가 빨리 뜨도록)
- 파일이 없는 칸은 보라~핑크 계열 그라데이션이 대신 보입니다.
- 컷 수를 바꾸려면 index.html 의 .intro-cut 줄을 복사하거나 지우면 됩니다.
- .png 나 .webp 를 쓰려면 index.html 에서 해당 줄의 파일 이름(확장자)만 바꾸면 됩니다.
